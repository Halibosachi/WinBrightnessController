# WinBrightnessController 🔆

*[English](#english-version) | [Türkçe](#türkçe-sürüm)*

<h2 id="english-version">🇬🇧 English Version</h2>

An ultra-lightweight, background-running Windows application written in C++ that allows you to control physical monitor brightness directly via global hotkeys. 

Built with the native Windows API (`HighLevelMonitorConfigurationAPI`), this tool bypasses heavy frameworks to deliver maximum performance with near-zero system footprint.

### ✨ Key Features
* **Global Hotkeys:** Adjust brightness instantly from anywhere, even while in-game or full-screen.
* **On-Screen Display (OSD):** Displays a brief, green text overlay showing the current brightness percentage.
* **Ultra-Lightweight:** Consumes only **~0.8 MB of RAM** and **%0 CPU** while running in the background.
* **Auto-Startup:** Seamlessly integrates with the Windows Registry to start automatically on boot.

### ⌨️ Hotkeys
| Action | Shortcut |
| :--- | :--- |
| **Increase Brightness (+10%)** | `Ctrl + Alt + Up Arrow` |
| **Decrease Brightness (-10%)** | `Ctrl + Alt + Down Arrow` |
| **Quit Application** | `Ctrl + Alt + Q` |

### 🚀 How to Use
1. Go to the **[Releases](../../releases)** section on the right side of this page.
2. Download the latest `Brigthness.exe` file.
3. Run the executable. It will silently run in the background and is ready to use!

<h2 id="türkçe-sürüm">🇹🇷 Türkçe Sürüm</h2>

C++ ile yazılmış, fiziksel monitör parlaklığını evrensel klavye kısayolları (global hotkeys) ile doğrudan kontrol etmenizi sağlayan ultra hafif bir arka plan uygulamasıdır.

Doğrudan Windows API (`HighLevelMonitorConfigurationAPI`) kullanılarak geliştirilen bu araç, hantal framework'leri aradan çıkararak sıfıra yakın sistem tüketimiyle maksimum performans sunar.

### ✨ Temel Özellikler
* **Evrensel Kısayollar:** Oyundayken veya tam ekrandayken bile parlaklığı anında değiştirin.
* **Ekran Göstergesi (OSD):** Parlaklık değiştiğinde ekranda anlık yüzdeyi gösteren yeşil bir metin belirir.
* **Ultra Hafif Mimari:** Arka planda çalışırken yalnızca **~0.8 MB RAM** ve **%0 CPU** tüketir.
* **Otomatik Başlatma:** Windows Kayıt Defteri'ne (Registry) entegre olarak sistem açılışında otomatik başlar.

### ⌨️ Kısayol Tuşları
| İşlem | Kısayol |
| :--- | :--- |
| **Parlaklığı Artır (+%10)** | `Ctrl + Alt + Yukarı Ok` |
| **Parlaklığı Azalt (-%10)** | `Ctrl + Alt + Aşağı Ok` |
| **Programı Kapat** | `Ctrl + Alt + Q` |
